# Security and Disclosure Boundary

This repository is a **public portfolio showcase**.

## Never publish here

- production credentials or secrets;
- API keys, tokens, or passwords;
- real contractor or employee personal data;
- confidential evaluation results;
- internal IP addresses or network diagrams;
- proprietary procurement documents;
- production database dumps;
- private source code copied from organizational systems.

## Allowed content

- synthetic examples;
- sanitized screenshots;
- conceptual architecture;
- generic workflows;
- non-sensitive technology descriptions;
- public-facing documentation.

## Disclosure principle

The goal is to demonstrate product thinking and system architecture without exposing operational or organizational information.
